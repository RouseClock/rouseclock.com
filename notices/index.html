Note on the LGPL components

The Arduino core, ESPAsyncWebServer and AsyncTCP are LGPL. Distributing a firmware binary that links them while keeping the rest of the source private is common, but LGPL asks that users be able to relink the firmware with a modified version of those libraries (usually done by offering the application's object files on request). Worth a check with someone qualified before a commercial release.
