Install Rouse

Put the Rouse firmware on a new board, straight from your browser. Version 0.5.3-beta.

This page is open as a file on your computer. The Install buttons only work when the page comes from a web address (https://…, or http://localhost for testing): opened as a file, the browser won't let the page read the firmware or reach the USB port.
This page needs a secure address. Browsers only let pages reach a USB port when they're served over https:// (look for the padlock). Ask your web host to turn on HTTPS for this site (often called SSL or Let's Encrypt, and usually free), then open the page with https:// at the start.
This browser can't talk to USB devices. Use Chrome or Microsoft Edge on a Windows, Mac, Linux or ChromeOS computer. (Phones, tablets, Safari and Firefox can't install firmware.)

1. Plug in the board

  1. Connect the board to this computer with a USB-C cable. It must be a data cable; some cables only charge.
  2. Pick your board below and click Install.
  3. Choose the board's port in the list that appears (it may be called USB JTAG/serial debug unit, USB Single Serial, CH340 or similar) and click Connect.

Erase the device? On a brand-new board, either answer is fine. On a clock that already runs Rouse, choose not to erase and your alarms, themes, photos and WiFi are kept. Erasing starts completely fresh.

3. Set it up

When the install finishes, the board restarts. A new board (or an erased one) shows WiFi setup. Follow the Operating Manual's First setup chapter: join the Rouse-XXXX network with your phone and pick your home WiFi. From then on, updates are installed from the clock's own web page (Settings → Firmware); you won't need this page again for that board.

If it doesn't connect

  • No port in the list: try another USB cable (a data cable) or another USB port. On Windows, the CYD may need the CH340 driver from the board maker.
  • "Failed to connect" or it stops at "Preparing": put the board in download mode: hold its BOOT button, press and release RESET, then release BOOT. Click Install again.
  • It worked the second time: that's normal for the Freenove and Waveshare, whose USB port restarts during the install. Reload this page and try again.
  • The install finished but the screen stays dark: press RESET once (or unplug and replug the board).
